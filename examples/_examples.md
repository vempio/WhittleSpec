# Public example corpus

Clean-room, illustrative specs cited by name elsewhere in the skill corpus (seed
length, requirements shape, etc.). Every path cited as "an example of X" must be
listed here — `build/ws-check-examples.sh` checks both directions: that each
listed path exists, and that every example citation in the corpus names a path
listed here. Keep this list in sync when an example is added, renamed, or retired.

| Path | Cited for |
|------|-----------|
| `examples/example-offline-sync/seed.md` | a long seed that earns its length (multiple open questions, real scoping trade-offs) |
| `examples/example-csv-export/seed.md` | a short seed (~36 lines) that covers everything needed for a small, clear-scope item |
